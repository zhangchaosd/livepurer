# LivePurer 界面重构

[Figma 交互原型](https://www.figma.com/design/Ufe0pLRyK97YtUwi6UQs2y) 包含直播播放、IPTV 草稿两条核心路径，以及可点击的页面导航。原型采用 Simple Design System 组件；产品实现使用 Vue 单文件组件与统一样式，视觉细节以运行界面为准。

## 页面与核心流程

| 页面 | 主要操作 | 状态与恢复 |
| --- | --- | --- |
| 总览 | 输入平台与房间号直接播放；进入最近打开的房间 | 显示实际系统连接状态；数据分别加载，失败可重试 |
| 直播播放 | 选平台 → 填房间 → 播放；查询后收藏 | 连接、缓冲、暂停、停止、失败与不支持状态；停止/导航释放连接，失败可重连或复制地址 |
| 我的收藏 | 建收藏夹、搜索主播/房间、直接播放、复制独立 M3U | 原生对话框管理焦点；删除确认；保存失败保留编辑内容 |
| IPTV 频道 | 增删、上下移动、编辑名称/图标 → 保存 → 电视订阅 | 校验空值/重复项/图标 URL；草稿状态、撤销修改、保存后更新订阅 |
| 设置 | 服务与账号分组；按需展开代理和凭据 | 独立保存状态；刷新不覆盖草稿；保存后提示重启 |

## 界面约定

- 浅色工作区、白色面板、森林绿主操作、深色播放器；页面的主操作与次要操作保持一致。
- 系统中文字体优先，英文字体采用 Inter/系统字体；图标为随二进制内置的 SVG，无外部字体和图片网络依赖。
- 桌面使用固定侧栏；小屏改为顶部导航、单列内容与频道卡片，保存栏固定在视口底部附近。
- 按钮和输入具有键盘焦点样式；图标按钮提供可访问名称；对话框支持 Escape、焦点限制和关闭后焦点恢复。
- 错误提示不会自动消失。成功提示自动关闭；服务状态按请求结果显示，失败时不显示虚假的“运行中”。
- 房间信息查询取消旧请求并校验目标，避免快速切换房间时出现旧结果。
- 最近打开最多保存 8 条，存于当前浏览器。频道与设置草稿在页内导航时保留，关闭/刷新页面有未保存提醒。
- 分享地址由后端检测运行程序的局域网 IPv4，优先 192.168 网段；订阅、收藏夹订阅与复制播放地址统一使用检测结果并保留端口。未检测到局域网地址时不显示回环地址。下载 M3U 时也会替换回环主机，浏览器内部播放仍走同源请求。
- 系统状态每 15 秒更新，页面不可见时暂停自动刷新。

## 工程结构

- `web/src/App.vue`：导航、页面容器、全局提示与确认框。
- `web/src/views/`：五个独立页面。
- `web/src/components/`：图标、对话框、空状态、房间表单、订阅地址组件。
- `web/src/composables/useConsole.ts`：业务状态、API 操作、草稿快照及请求竞争处理。
- `web/src/composables/usePlayer.ts`：FLV 播放器与资源生命周期。
- `web/src/lib/`：API、数据类型与频道验证。
- `web/tests/console.spec.ts`：桌面与手机交互测试，使用隔离模拟后端。

## 构建与交付

`make build` 先构建前端，再通过 `go:embed` 嵌入当前平台的 `bin/pure-live`。运行时不依赖 Node.js、npm、Docker 或单独部署的 UI 目录。服务继续使用 `config/server.yaml` 与 `config/account.yaml`；未配置时按 README 从示例文件创建。

发布流程仅生成跨平台二进制发行包与校验和。CI 验证类型检查、浏览器交互、前端构建、Go 静态检查、测试与可执行程序构建。

## 验证范围

```shell
npm --prefix web run typecheck
cd web && npx playwright install chromium && npm test
make build
go vet ./...
go test ./...
```

浏览器测试覆盖桌面和手机布局、频道校验/排序/失败重试/撤销、收藏搜索/创建/取消删除/编辑失败、对话框焦点、设置草稿保留、查询与收藏、播放失败恢复、服务不可用状态。实际平台开播状态、网络取流、电视硬件解码仍依赖各自运行环境。
